# Civic Issue Reporting System

This is a frontend web application that allows users to report civic issues like potholes, garbage, streetlight problems, etc.

## Features
- Report issues with photo, category, and location
- Dynamic reward calculation based on priority
- Token-based reward system
- Track submitted reports
- Token redemption system
- Malpractice reporting feature
- Data stored using browser localStorage

## Tech Stack
- HTML
- CSS
- JavaScript

## How it Works
Users can submit civic issues with details. The system calculates rewards based on issue type and location priority. Reports and tokens are stored using localStorage, and users can track their reports and redeem tokens.

## Note
This is a frontend prototype. In real-world applications, a backend would be used for data storage and verification.
